untuk melihat semua branch lokal yang ada dikomputer : <git branch>
Untuk memastikan tidak ada perubahan file yang belum disimpan atau di-commit sebelum pindah branch : <git status>
Digunakan untuk pindah branch : <git switch <nama_branch> >
